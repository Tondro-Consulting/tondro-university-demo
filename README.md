# Tondro University — demo admissions site

A small, fictional university admissions website used to demonstrate an Agentforce chat agent that answers
applicant questions from a school's own web content: each page section is loaded into Salesforce Knowledge,
and the agent answers only from it.

Tondro University, its programs, dates, fees, emails and phone numbers are invented for demonstration.

Static HTML and CSS, no build step. Served with GitHub Pages from `main`.

The site was visually redesigned (editorial typography, real navigation, page heroes, refreshed tables and footer). All page URLs, filenames, section ids, and every fact on the pages were preserved, and the Agentforce chat widget is unchanged.
